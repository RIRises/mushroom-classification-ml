# Классификация грибов (Mushroom Classification)

Взял датасет с Kaggle: https://www.kaggle.com/datasets/uciml/mushroom-classification. 
Файл `mushrooms.csv` лежит в репо.

Почему: все фичи категориальные (22 шт.), пропуски только в stalk-root, классы сбалансированы. Идеально, чтобы быстро прогнать пайплайн.

Гипотезы
1. Логистическая регрессия выдаст accuracy >= 0.95, так как данные хорошо разделимы.
2. Дерево решений без ограничений переобучится.
3. odor будет главным признаком по feature importance.
4. Удаление строк с пропуском в stalk-root не сильно испортит качество по сравнению с заполнением моды.
5. Из-за баланса классов F1 macro почти не будет отличаться от accuracy.
